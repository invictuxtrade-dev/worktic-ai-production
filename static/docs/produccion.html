Infraestructura

Desplegar Worktic AI

La versión incluye Dockerfile, render.yaml y endpoints de salud. Antes del lanzamiento valida persistencia, secretos y backups.

Variables

APP_PORT=8080
DATABASE_DSN=file:/var/data/worktic.db?_pragma=foreign_keys(1)&_pragma=busy_timeout(5000)
BASE_URL=https://app.tudominio.com
OPENAI_API_KEY=...
CHANNEL_ENCRYPTION_KEY=...
# Agrega credenciales OAuth y pagos según los módulos habilitados.

Endpoints de salud

GET/healthz
GET/readyz

Checklist previo

  • Dominio y HTTPS activos.
  • Disco persistente montado.
  • Base de datos y backups verificados.
  • Credenciales por variables de entorno.
  • OAuth con URLs finales.
  • Webhooks apuntando al dominio.
  • Logs y alertas.
  • Prueba de reinicio sin pérdida de sesiones.
EscalabilidadSQLite es útil para desarrollo y despliegues pequeños. Para alta concurrencia, migra a PostgreSQL y usa Redis para colas, sesiones y límites.
