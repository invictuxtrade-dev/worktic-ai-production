Telegram Bot API

Telegram es una opción rápida para validar el agente y las publicaciones.

Crear el bot

Abrir BotFatherBusca la cuenta oficial @BotFather.
Ejecutar /newbotIndica nombre y username terminado en bot.
Copiar tokenGuárdalo de manera segura.
Agregar al canalConvierte el bot en administrador si publicará.
Ingresar datosConfigura token y @canal o ID -100… en Worktic.
ProbarUtiliza el botón de prueba de conexión.
Token privadoQuien posee el token puede controlar el bot. Rótalo desde BotFather si se expone.

Contenido

La integración puede enviar texto, fotografías y captions. Para documentos, video o grupos multimedia se debe validar que la versión del conector incluya el método correspondiente.
