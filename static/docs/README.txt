WORKTIC AI — DOCUMENTACIÓN HTML5

1. Abra index.html directamente en un navegador.
2. Para una experiencia idéntica a producción, sirva la carpeta con un servidor web.
   Python: python -m http.server 8081
3. Publique la carpeta completa en /docs o en un subdominio como docs.workticai.com.

La documentación es responsive, tiene búsqueda, navegación lateral, tabla de contenido, impresión y botones para copiar código.
