Grupos potenciales guardados

Directorio privado para que tu equipo evalúe reglas, relevancia y posibilidad de colaboración.

Telegram

  1. Agrega el bot al grupo.
  2. Concede solo los permisos necesarios.
  3. Desactiva Privacy Mode en BotFather si debe leer mensajes generales.
  4. Copia el ID o @username del grupo.

WhatsApp

  1. Conecta el número mediante QR.
  2. Agrega ese número al grupo.
  3. Activa ALLOW_GROUP_MESSAGES=true.
  4. Usa el JID del grupo terminado en @g.us.

Facebook

Worktic no puede buscar ni publicar automáticamente en todos los grupos. La administración solo se habilita cuando Meta, el grupo y los permisos de la aplicación lo autorizan.

Suscripciones

Guías de puesta en marcha

Telegram

  1. Abre Telegram y busca @BotFather.
  2. Envía /newbot.
  3. Define nombre y usuario terminado en bot.
  4. Copia el token y pégalo en Canales.
  5. Abre el bot y envía /start.

Messenger

  1. Crea o usa una Página de Facebook.
  2. Agrega Messenger a tu app de Meta.
  3. Genera un Page Access Token.
  4. Configura el webhook mostrado en Canales.
  5. Suscribe la página a los eventos de mensajes.

OpenAI central

El propietario configura OPENAI_API_KEY en el archivo .env. La clave no se solicita a los usuarios.

Uso responsable

WhatsApp QR debe priorizar atención entrante y seguimientos moderados. Las campañas deben migrar a Cloud API oficial.
